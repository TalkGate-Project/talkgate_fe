## 1. 준비

- 데스크톱 폭 **≥1080px** (여기서만 `zoom: 0.8` 적용)
- 라이트/다크 모드 둘 다 확인이 필요한 항목은 별도 표시(🌗)
- 브레이크포인트 경계 확인용으로 브라우저 폭을 **770px**로 만들 수 있게 준비
  (이 앱의 모바일↔데스크톱 경계는 768이 아니라 **780**)

## 2. 최우선 — 회귀 위험 높은 것부터

### 2-1. 통계 페이지 차트 7종 (`a68c99c`)

판정 기준이 768 → 780으로 이동했다. **768~779px 구간에서만** 렌더가 달라진다.

- [ ] 폭 **770px**에서 통계 페이지 진입 → 차트가 모바일 형태로 그려지는가
      (기존에는 이 구간에서 레이아웃만 모바일이고 차트는 데스크톱 설정이었다)
- [ ] 폭을 770 ↔ 900 사이로 천천히 드래그 → 780 경계에서 한 번만 전환되는가
      (경계를 넘지 않는 드래그 중엔 리렌더가 없어야 정상)
- [ ] 배정 현황 차트 / 납부 현황 차트 / 상태별 차트 / 등록 추이 차트 축 라벨·바 두께 정상
- [ ] 등록 상세 테이블 스켈레톤 행 수 (모바일 7 / 데스크톱 10)
- [ ] 통계 필터 모달이 모바일에서 전체화면, 데스크톱에서 중앙 정렬로 뜨는가

### 2-2. 피커 3종 전반 회귀 (`1243414`)

내부 구현이 통째로 훅으로 교체됐다. **모든 피커가 정상 동작하는지**가 핵심.

- [ ] 열기 / 날짜 선택 / 닫기
- [ ] 바깥 클릭으로 닫힘
- [ ] **Esc**로 닫힘
- [ ] 모달 안에서 열었을 때 모달 위로 올라오는가 (z-index)
- [ ] 스크롤·창 크기 변경 시 패널이 인풋을 따라오는가

## 3. 화면별 점검

### 3-1. 대시보드 — 달력 & 일정 (`4af4f84`, `1243414`)

- [ ] 월 선택기 패널이 인풋 **정중앙 아래**에 붙는가 (좌측으로 밀리지 않음)
- [ ] 월 ↔ 연도 모드 전환 시 패널 위치가 다시 잡히는가
- [ ] 일정 생성 모달의 날짜/시간 피커 정상

### 3-2. 통계 — 수임료 납부 현황 (`4af4f84`)

- [ ] 월 선택기(`w-[227px]`, 대시보드보다 넓음) 패널도 중앙 정렬되는가
- [ ] 화면 아래쪽에 있으므로 **세로 위치**도 확인 — 인풋 바로 아래 8px

### 3-3. SMS 예약 발송 모달 (`ae6f2f8`, `1243414`)

여기가 "위로 뜨는" 케이스 확인에 가장 좋다.

- [ ] 날짜 피커를 열었을 때 위로 뜬다면 **간격이 8px 정도**인가
      (기존에는 80px 넘게 벌어졌다)
- [ ] 아래에 공간이 충분하면 **아래로** 뜨는가 (과잉 플립 해소 확인)
- [ ] 시간 피커도 동일하게 확인
- [ ] 회생·파산 쪽 SMS 모달(`DebtReliefSmsModal`)도 동일

### 3-4. 고객 등록 / 고객 상세 — 생년월일 (`4efd5b5`)

- [ ] 연도 목록에서 **1920년까지** 내려가는가
- [ ] `maxDate`(오늘)가 걸려 있어 미래 연도가 목록에 없는가
- [ ] 연도 → 월 → 일 3단계로 좁혀지는가
- [ ] 🌗 선택된 연/월/일 셀의 **글자가 배경에 묻히지 않는가** (다크모드 필수)

### 3-5. 고객 목록 — 신청시간 범위 필터 (`4efd5b5`)

강제 리마운트 해킹을 제거한 자리라 여기가 제일 의심스럽다.

- [ ] **초기화** 버튼 → 시작·종료 둘 다 비워지는가
- [ ] 시작일을 종료일보다 **뒤로** 선택 → 종료일이 자동으로 비워지는가
- [ ] 그 직후 종료일 피커를 열면 뷰가 엉뚱한 달이 아니라 정상 위치인가

### 3-6. 가로 클램프 (`1243414`) — **신규 동작**

가로 클램프가 모바일 전용에서 **전 구간**으로 바뀌었다.

- [ ] 데스크톱에서 화면 **오른쪽 끝**에 있는 날짜 피커를 열었을 때
      패널이 화면 밖으로 나가지 않고 안쪽으로 당겨지는가
- [ ] 반대로, 여유가 있는 위치의 피커는 **평소대로 인풋 왼쪽 모서리 정렬**인가
      (클램프가 불필요하게 개입하면 안 됨)

### 3-7. 피커 외 포털 3종 (`708c825`) — 피커와 같은 버그가 있던 곳

셋 다 **화면 아래쪽에서 열어 위로 뜨게** 만드는 것이 확인 포인트다.

- [ ] **색상 팔레트 팝오버** (고객 카테고리 색상 등) — 위로 뜰 때 간격이 과하지 않은가
      (수정 전 약 60px 초과)
- [ ] 색상 팔레트가 화면 오른쪽 끝에서 잘리지 않는가 (가로 클램프도 함께 수정됨)
- [ ] **필터 드롭다운**(`filterFields`) — 위로 뜰 때 간격 (수정 전 약 44px 초과)
- [ ] **FilterModal 다중선택 드롭다운** — 페이지를 **아래로 스크롤한 상태에서**
      필터 모달을 열고 드롭다운 클릭 → 패널이 트리거 바로 아래에 붙는가
      (수정 전에는 스크롤량만큼 아래로 밀렸다)

### 3-8. 페이지네이션 (`691b5c3`)

- [ ] 데스크톱에서 페이지 버튼 **10개**, 모바일(<780)에서 **5개**
- [ ] `maxButtons` prop을 넘기는 화면이 있다면 그 값이 우선하는가

### 3-9. 기타 (`33f7b9c`, `691b5c3`)

- [ ] 근태 필터 모달 모바일/데스크톱 레이아웃
- [ ] 팀원 통계 필터 모달(`MemberStatsFilterModal`) 모바일/데스크톱

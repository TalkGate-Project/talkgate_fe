- [x] 🔴 체크 해제한 채무는 총채무·청산가치·면책액·AI 추천 계산에서 제외된다. (총채무 300만원으로 계산됨, AI 추천 문구에도 "총채무도 300만원" 명시)

   `totalDebtManwon <= 0` 가드에 걸려 "분석하기"가 100% 차단됨. `form.debts` 기준으로 통일해서 수정, 간편 모드로
